# 管理后台 UI v2：身份分发总控工作台

## 目标

继续按已确认的 UI v2 控制台方向推进，把身份模块从“团队、成员、Token 三段列表”收敛为“先判断分发链路是否齐备，再进入具体卡片处理”的首屏体验。

## 本轮范围

- 在身份模块顶部新增身份分发总控工作台。
- 工作台展示团队、成员、Token 和可分发订阅 4 个核心状态。
- 工作台展示团队归属、成员承接、订阅分发 3 个生命周期阶段卡。
- 所有新增元素必须在桌面和移动视口内无横向溢出、无遮挡。
- 不改后端接口，不改变现有团队、成员和 Token 操作语义。

## 验证

- `scripts/qa/ui-static.sh` 增加静态契约，防止身份工作台和阶段卡缺失。
- `scripts/qa/browser-login.sh` 增加浏览器断言，验证工作台数量、状态数量、阶段卡、关键符号和视觉边界。
- 完成后运行本地 QA、清理、公开仓库脱敏扫描、提交、推送和远程部署。
