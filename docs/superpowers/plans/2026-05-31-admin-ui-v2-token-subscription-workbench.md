# 管理后台 UI v2：Token 订阅分发工作台

## 目标

继续按已确认的 UI v2 控制台方向推进，把身份模块里的 Token/订阅区域从“卡片里找地址”收敛为“先扫读分发状态，再进入卡片复制或探测”的工作台体验。

## 本轮范围

- 在 Token 列表顶部新增订阅分发工作台。
- 工作台展示可用 Token 数、启用状态、订阅地址数量和地址来源摘要。
- 工作台展示通用 URI、Mihomo YAML、sing-box JSON 三种客户端格式卡。
- 所有新增元素必须在桌面和移动视口内无横向溢出、无遮挡。
- 不改后端接口，不改变现有 Token 操作语义。

## 验证

- `scripts/qa/ui-static.sh` 增加静态契约，防止工作台和格式卡缺失。
- `scripts/qa/browser-login.sh` 增加浏览器断言，验证工作台数量、三种格式符号和视觉边界。
- 完成后运行本地 QA、清理、公开仓库脱敏扫描、提交、推送和远程部署。
