# FluxGate 管理后台 UI v2：流量观测工作台

## 目标

继续沿用已确认的 UI v2 控制台方向，把流量模块从“图表和卡片直接堆叠”推进为先给出可扫读的观测工作台，再进入小时/日趋势、Token 用量和出口摘要详情。

## 本次增量

- 在流量模块面板顶部增加 `traffic-workbench`。
- 首屏展示 Token 用量、今日流量、24 小时活跃样本和出口摘要 4 个关键状态。
- 增加额度风险、最近小时和出口链路 3 个信号卡，帮助真实测试时快速判断统计链路是否有数据、是否存在超额风险、出口维度是否已经聚合。
- 保持桌面和移动端都不产生横向溢出，并沿用现有 Calm Ops 控件尺寸和卡片边界。

## 验收

- 静态 UI 契约要求流量模块提供工作台入口、渲染函数、信号卡和样式治理。
- 浏览器 QA 要求流量页存在 1 个工作台、4 个状态项、3 个信号卡，且 `量/钥/日/时/出/额` 符号齐全，无工作台溢出。
- 完整 `local-suite`、清理、公开仓库扫描、远端部署和真实可用探测通过后提交。
