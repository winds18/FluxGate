# 管理后台 UI v2：运维交付工作台

## 背景

运维模块承接交付收口、配置检查、发布、回滚和重启。当前页面已有操作卡和结构化结果卡，但用户进入运维模块后需要先理解每个按钮，缺少“当前是否可以发布、下一步做什么、配置是否有入站/上游/用户”的首屏判断。

## 范围

- 在运维模块顶部新增交付发布工作台。
- 工作台展示闭环进度、配置 Hash、入站和上游出口 4 个核心状态。
- 工作台展示来源、节点、虚拟网关、Token、策略和配置 6 个交付步骤卡。
- 保留原有收口、检查、发布、回滚和重启动作卡。

## 验收

- `scripts/qa/ui-static.sh` 要求运维模块存在工作台、渲染函数、步骤卡和样式治理。
- `scripts/qa/browser-login.sh` 要求运维工作台 1 个、状态项 4 个、步骤卡不少于 3 个，关键符号齐全且无视觉溢出。
- 本地完整 QA、清理和公开仓库脱敏扫描通过后再提交。
