# Admin UI v2 节点池工作台增量计划

## 目标

围绕用户反馈的“节点池信息难扫、卡片容易显得拥挤、UI 不够现代”，在不改动后端数据结构的前提下，把节点池默认首屏升级为更接近控制台的信息工作台：先看总体状态与重点地区，再进入地区聚合和单节点详情。

## 范围

- 在节点池地区聚合页顶部新增节点池工作台。
- 展示节点匹配、可用节点、地区类别、协议/来源 4 个关键状态。
- 展示 Top 地区健康卡，包含地区符号、节点数、可用数、占比和可用率进度条。
- 继续保留现有地区聚合、搜索、节点卡片、编辑和详情抽屉。
- 补静态 UI 契约和浏览器视觉 QA，校验工作台存在、关键符号存在、地区卡数量足够且无溢出。

## 验证

1. 先扩展 `scripts/qa/ui-static.sh` 和 `scripts/qa/browser-login.sh`，确认缺少工作台时静态检查失败。
2. 实现 `renderNodeWorkbench` 与对应 Calm Ops 样式后重新跑静态检查。
3. 运行完整本地验证套件，覆盖桌面和移动视觉 QA。
4. 清理临时文件、执行公开仓库脱敏扫描。
5. 提交、推送、部署，并用远程可用性探测确认控制面与订阅网关仍可真实测试。
