# Admin UI v2 虚拟网关工作台增量计划

## 目标

虚拟网关是订阅分发和 sing-box 入站配置之间的承接层。当前虚拟网关列表已经卡片化，但用户进入节点模块后仍要逐条卡片查看监听端口、启用状态、标签筛选和出口策略。本增量在不改动后端接口的前提下，为虚拟网关列表增加首屏工作台，让入站承载先可扫读，再进入单个网关编辑。

## 范围

- 在虚拟网关列表顶部新增虚拟网关工作台。
- 展示网关总数、启用网关、监听端口和标签筛选 4 个关键状态。
- 展示出口策略分布卡，按 selector 等策略聚合，并显示启用、监听端口和标签筛选数量。
- 保留现有虚拟网关卡片、行内编辑、保存和取消动作。
- 补静态 UI 契约和浏览器视觉 QA，校验工作台存在、关键符号存在、策略分布卡存在且无视觉溢出。

## 验证

1. 先扩展 `scripts/qa/ui-static.sh` 和 `scripts/qa/browser-login.sh`，确认缺少虚拟网关工作台时静态检查失败。
2. 实现 `renderVirtualNodeWorkbench` 与对应 Calm Ops 样式后重新跑静态检查。
3. 运行完整本地验证套件，覆盖桌面和移动视觉 QA。
4. 清理临时文件、执行公开仓库脱敏扫描。
5. 提交、推送、部署，并用远程可用性探测确认控制面与订阅网关仍可真实测试。
